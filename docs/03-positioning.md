# 03. 채널 포지셔닝

---

## 1. 포지셔닝 선언문 (한 문장)

> **혼자 일하는 사람이 반복 업무를 AI로 없애는 전 과정을, 편집으로 감추지 않고 실패까지 화면 그대로 보여주는 채널.**

### 이 문장이 방어하는 세 가지 차별점

| 경쟁 채널의 관행 | 우리의 선택 | 시청자가 얻는 것 |
|---|---|---|
| "이 도구 좋아요" 소개 후 끝 | **끝까지 작동시켜 결과 수치를 보여준다** | 따라 하면 진짜 된다는 확신 |
| 안 되는 부분은 편집으로 잘라냄 | **막힌 지점과 해결 과정을 남긴다** | 자기가 막혔을 때의 해답 |
| 화려한 데모, 실무엔 못 씀 | **실제 업무에 붙여 며칠 돌린 결과를 보고한다** | 도입 판단 근거 |

**한 줄 요약: "데모가 아니라 도입기(導入記)."**

---

## 2. 채널 페르소나 — 얼굴 없이 인격을 만드는 법

무얼굴 채널의 최대 약점은 **정체성이 없어 구독으로 이어지지 않는 것**이다. 얼굴 대신 아래 5개 요소로 인격을 고정한다.

| 요소 | 규정 | 이유 |
|---|---|---|
| **호칭** | 시청자를 "여러분"이 아니라 **"혼자 일하는 분"**으로 부른다 | 대상이 특정되면 소속감이 생긴다 |
| **말투** | 단정형·짧은 문장. 과장 금지. "미쳤습니다" 류 금지 | 실무자 대상 신뢰의 언어 |
| **목소리** | **단일 합성 음성 고정.** 영상마다 바꾸지 않는다 | 목소리가 곧 얼굴이다 |
| **시그니처 구조** | 모든 영상이 "결과 먼저 → 과정 → 실패 → 판정"으로 흐른다 | 구조가 브랜드가 된다 |
| **시그니처 문장** | 마무리 고정 멘트: **"됩니다. 다만 조건이 있습니다."** | 반복이 기억을 만든다 |

### 음성 설정 규칙
- 합성 음성 1개를 선택해 **152일 내내 바꾸지 않는다.**
- 속도는 기본 대비 약간 빠르게(정보 밀도 인상).
- **영상 설명란에 합성 음성 사용을 공시한다** (정책 요구사항이자 신뢰 요소).

## 3. 채널명 후보

| 후보 | 콘셉트 | 장점 | 단점 |
|---|---|---|---|
| **혼자 일하는 법** | 대상 직격 | 검색·기억 최상, 확장성 좋음 | 다소 평범 |
| **자동화 도입기** | 포맷 직격 | 콘텐츠 형식이 이름에 박힘 | 대상이 덜 명확 |
| **1인 운영실** | 정체성형 | 브랜드화 유리 | 첫인상 모호 |
| **되는 자동화** | 판정형 | 시그니처와 연결됨 | 검색 약함 |

**권장: `혼자 일하는 법`** — 대상·문제·검색성을 한 번에 잡는다. 부제로 `AI 업무 자동화 도입기`.

## 4. 채널 아트 & 시각 정체성

### 고정 규칙 (한 번 정하고 152일 유지)

| 항목 | 규정 |
|---|---|
| 주색 | 진한 남색 계열 1색 + 강조색 1색(형광 계열) — **2색을 넘기지 않는다** |
| 서체 | 굵은 고딕 1종. 썸네일 텍스트 전용 |
| 썸네일 텍스트 | **최대 7글자, 2줄 이내** (모바일에서 읽혀야 함) |
| 화면 녹화 | 항상 동일한 다크 테마 + 동일 확대 배율 |
| 인트로 | **없음.** 0초부터 본론 (유지율 최우선) |
| 아웃트로 | 마지막 12초 고정 최종화면 |

### 채널 배너 문구
```
반복 업무를 없애는 실전 기록
매주 화·목·토 발행
```

## 5. 포지셔닝 맵 — 우리가 서 있는 좌표

```
                    깊이 있음 / 실무
                          ▲
                          │
      "도입기"            │        전문 개발자 채널
      ◆ 우리 채널          │        (진입장벽 높음)
                          │
  대중적 ─────────────────┼───────────────── 전문적
                          │
      AI 뉴스 요약 채널     │        기업 공식 문서
      TTS 슬라이드쇼        │
                          │
                          ▼
                    얕음 / 소개
```

**빈 좌표: "실무자가 실제로 도입할 수 있는 깊이인데, 개발자가 아니어도 따라올 수 있는 수준."**
위쪽은 개발자 전용이라 대중이 못 따라오고, 아래쪽은 정보가 없어 신뢰가 안 쌓인다. 그 사이가 비어 있다.

---

## 6. 하지 않을 것 (포지셔닝 방어선)

명시적으로 배제해야 포지셔닝이 흐려지지 않는다.

- ❌ AI 뉴스 요약 (원본성 없음, 정책 위험, 소모적)
- ❌ "AI로 월 1000만원" 류 수익 자극 (신뢰 파괴, 광고주 기피 카테고리)
- ❌ 코딩 강의 (대상이 개발자로 이동)
- ❌ 자극적 썸네일 (실무자 시청자층과 불일치, 재방문율 하락)
- ❌ 검증 안 한 도구 소개 (한 번이면 채널 신뢰가 끝난다)

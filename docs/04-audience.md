## 1. 핵심 시청자 페르소나

### 1순위: "직접 다 하는 사장" (전체 시청의 45% 목표)

| 항목 | 내용 |
|---|---|
| 상황 | 1인~5인 사업체 운영. 대표가 영업·정산·고객응대·마케팅을 전부 함 |
| 연령 | 32~48세 |
| 기술 수준 | 엑셀은 능숙, 코드는 못 씀. "설치"까지는 하지만 "설정"에서 막힘 |
| 하루 중 시청 시점 | 밤 10시~자정, 주말 오전 |
| 시청 기기 | 모바일 55% / PC 30% / TV 15% |
| **핵심 고통** | "이 일을 없앨 수 있다는 건 아는데, 어디서부터 손대야 할지 모르겠다" |
| **원하는 결과** | 주 5시간 되찾기 |
| 구매력 | 높음. 월 3~10만원 도구 결제에 저항 없음 → **RPM 상승 요인** |

### 2순위: "회사에서 몰래 자동화하는 실무자" (35%)

| 항목 | 내용 |
|---|---|
| 상황 | 마케팅·기획·운영 담당. 반복 보고서·데이터 정리에 시간을 뺏김 |
| 연령 | 27~38세 |
| **핵심 고통** | "야근의 80%가 복붙 작업이다" |
| **원하는 결과** | 남들보다 빨리 끝내고 인정받기 |
| 특징 | 저장·공유율이 가장 높은 층 → **알고리즘 신호에 유리** |

### 3순위: "예비 창작자·부업 탐색자" (20%)

| 항목 | 내용 |
|---|---|
| 상황 | 콘텐츠·부업으로 수입원을 만들려 함 |
| **핵심 고통** | "혼자서 콘텐츠 만들 시간이 없다" |
| 주의 | **이 층에만 맞추면 채널이 '돈 버는 법' 채널로 변질된다.** 20%로 제한. |

## 2. 시청자가 실제로 검색하는 말 (JTBD 기반)

시청자는 "AI 자동화"라고 검색하지 않는다. **자기 고통을 검색한다.**

| 시청자의 실제 상황 | 실제 검색어 형태 | 우리가 만들 영상 |
|---|---|---|
| 매달 같은 정산표를 만든다 | "엑셀 자동으로 정리하는 법" | 정산 파이프라인 구축 실황 |
| 문의 답장에 하루가 간다 | "고객 문의 자동응답 만들기" | 응대 자동화 도입기 + 실패 사례 |
| 블로그·SNS 글감이 없다 | "콘텐츠 자동 생성 도구 비교" | 도구 3종 실측 비교 |
| 도구가 너무 많아 뭘 쓸지 모른다 | "○○ vs ○○ 뭐가 나은가" | 비교·판정 영상 |
| 써봤는데 안 됐다 | "○○ 안 될 때" / "○○ 실제 후기" | 90일 사용 후기·한계 정리 |

> **콘텐츠 기획 원칙: 도구 이름이 아니라 "막힌 순간"에서 제목을 뽑는다.**

## 3. 시청자 여정 설계 (첫 접촉 → 구독 → 팬)

| 단계 | 시청자 상태 | 우리가 배치하는 것 | 성공 지표 |
|---|---|---|---|
| **1. 발견** | 숏폼/검색에서 우연히 봄 | "결과 먼저" 30초 클립 | 숏폼 완주율 70%+ |
| **2. 검증** | "이 채널 믿을 만한가" | 실패까지 보여주는 롱폼 1편 | AVD 5분+ |
| **3. 구독** | "다음 것도 보고 싶다" | 재생목록 + 시리즈 예고 | 조회당 구독 1%+ |
| **4. 습관** | 발행일을 안다 | 고정 요일 발행 | 재방문 시청자 30%+ |
| **5. 전환** | "이 사람한테 배우고 싶다" | 템플릿 배포 → 이메일 수집 | (D90 이후) |

**핵심: 2단계(검증)에서 대부분이 이탈한다.** 무얼굴 채널은 신뢰 자산이 없기 때문이다.
→ 그래서 **"실패를 보여주는 것"이 우리의 전환 장치**다. 실패를 보여주는 사람만 믿을 수 있다.

## 4. 시청자가 이탈하는 지점 (사전 방어)

| 이탈 지점 | 원인 | 방어 설계 |
|---|---|---|
| 0~15초 | "또 뻔한 소개 영상" | 인트로 삭제, 완성 결과부터 노출 |
| 1~2분 | "설치 과정 지루함" | 설치는 3배속 + 자막 요약으로 압축 |
| 중반 | "내 상황과 다름" | "이 경우엔 이렇게" 분기 안내 |
| 결말 직전 | "결론이 안 나옴" | 마지막 60초에 **판정**(쓸 것 / 쓰지 말 것) 고정 배치 |

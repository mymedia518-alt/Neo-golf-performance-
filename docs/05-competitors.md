# 05. 경쟁자 분석 — 프레임워크와 실행 절차

경쟁자 목록을 남이 만들어 주면 3개월 뒤 낡는다. **매달 스스로 갱신하는 시스템**을 만든다.

---

## 1. 경쟁자 3계층 분류

| 계층 | 정의 | 우리가 취할 태도 |
|---|---|---|
| **직접 경쟁** | 같은 주제 + 같은 포맷 + 구독자 1천~10만 | **패키징을 해부한다.** 이 층이 우리 상한선을 알려준다 |
| **주제 경쟁** | 같은 주제, 다른 포맷(대형 채널·얼굴 출연) | **주제만 가져오고 각도를 바꾼다.** 정면 승부 금지 |
| **주의력 경쟁** | 시청자가 우리 대신 보는 모든 것 | 썸네일 대비 우위만 확보 |

> **가장 중요한 층은 "직접 경쟁"이 아니라 구독자 1천~1만 구간의 신생 채널이다.**
> 대형 채널은 브랜드 힘으로 이기는 것이라 배울 게 없다. **최근 6개월 안에 성장한 소형 채널이 "지금 알고리즘이 뭘 미는지"를 알려준다.**

---

## 2. 경쟁자 발굴 절차 (매월 1회, 60분)

1. **검색 수집** — 유튜브 검색창에 서브 니치 키워드 입력 → 자동완성 20개 수집
2. **필터** — 필터를 `이번 달` + `조회수순`으로 설정 → 최신 승자만 남긴다
3. **선별** — 구독자 1천~5만인데 조회수가 구독자 수를 넘긴 영상 = **알고리즘이 밀어준 증거**
4. **기록** — `templates/competitor-teardown.md`에 5개 채널 기록
5. **추출** — 아래 3가지만 뽑는다

| 뽑을 것 | 뽑지 말 것 |
|---|---|
| 제목의 **문장 구조** | 제목의 주제(그대로 베끼면 후발주자로 밀림) |
| 썸네일의 **대비 구조** | 썸네일 디자인 |
| 첫 15초의 **정보 배치 순서** | 말투 |

---

## 3. 경쟁 우위 도출 — "빈틈 4분면"

경쟁자를 볼 때 다음 4개 칸 중 **비어 있는 칸**을 찾는다.

| | 얕게 다룸 | 깊게 다룸 |
|---|---|---|
| **성공만 보여줌** | AI 뉴스 채널 (포화) | 대형 튜토리얼 채널 (포화) |
| **실패도 보여줌** | 리뷰 채널 일부 | ⬅ **여기가 비어 있다. 우리 자리.** |

**"깊게 다루면서 실패도 공개"는 만들기 귀찮아서 아무도 안 한다. 그래서 비어 있다.**
그리고 정확히 그 귀찮음이 자동화로 상쇄된다 — 화면 녹화를 통으로 남기면 실패 장면이 자동으로 확보된다.

---

## 4. 경쟁자에게서 절대 베끼면 안 되는 것

| 항목 | 이유 |
|---|---|
| 영상 주제를 그대로 | 유튜브는 동일 질의에서 먼저 올린 채널을 우대한다. 후발은 조회수의 5%만 가져간다 |
| 썸네일 스타일을 그대로 | 시청자가 두 채널을 구분 못 하면 큰 쪽을 클릭한다 |
| 발행 요일을 그대로 | 같은 시간에 같은 시청자를 두고 싸운다 |

**대신 할 것: 같은 주제를 "그 다음 질문"으로 받아친다.**
- 경쟁자: "○○ 도구 사용법" → 우리: "○○ 30일 써보고 결국 지운 이유"
- 경쟁자: "AI로 자동화하는 법" → 우리: "자동화했다가 오히려 일이 늘어난 3가지"

---

## 5. 경쟁 강도 판정 기준 (주제 선정 시 매번 적용)

새 영상 주제를 정할 때 아래를 60초 안에 체크한다.

| 신호 | 진입 판정 |
|---|---|
| 상위 10개 중 3개 이상이 6개월 이내 + 구독자 1만 미만 채널 | 🟢 **진입** — 알고리즘이 신규 채널에 열려 있음 |
| 상위 10개가 전부 구독자 10만+ 채널 | 🔴 **회피** — 이길 수 없음 |
| 상위 결과가 주제와 어긋남(정확히 답한 영상이 없음) | 🟢🟢 **최우선 진입** — 수요는 있고 공급이 없음 |
| 상위 결과가 전부 2년 이상 된 영상 | 🟢 **진입** — 갱신 수요 존재 |

> **가장 좋은 주제는 "검색은 되는데 만족스러운 답이 없는 질의"다.** 이걸 찾는 데 쓰는 10분이 편집 3시간보다 가치 있다.

# 07. 비디오 포맷 규격 — 초 단위 설계

포맷을 고정해야 자동화가 가능하다. **아래 타임코드는 협상 대상이 아니다.**

---

## A. 롱폼 표준 구조 (15분 기준)

| 구간 | 시간 | 내용 | 목적 | 실패 시 결과 |
|---|---|---|---|---|
| **훅** | 0:00–0:20 | **완성된 결과를 먼저 보여준다.** 말보다 화면 | 15초 이탈 방어 | 여기서 40% 이탈 |
| **약속** | 0:20–0:45 | "이 영상 끝나면 당신도 이걸 갖게 됩니다" + 소요 시간 명시 | 시청 계약 체결 | 목적 없이 방황 |
| **지도** | 0:45–1:10 | 3단계 목차를 화면에 표시 | 남은 시간 예측 가능 → 이탈 방지 | 길이에 질림 |
| **본문 1** | 1:10–5:00 | 준비·설계 (설치는 3배속 압축) | | 지루함 이탈 |
| **재훅 1** | 5:00–5:15 | "여기서 문제가 생깁니다" | 중반 이탈 방어 | 중반 급락 |
| **본문 2** | 5:15–9:30 | 핵심 구축 | 가치 전달 | |
| **실패 구간** | 9:30–11:30 | **막힌 지점과 해결** | 신뢰 형성·차별화 | 채널 정체성 소실 |
| **재훅 2** | 11:30–11:45 | "결과가 얼마나 달라졌는지 보시죠" | 종반 이탈 방어 | |
| **실측 결과** | 11:45–13:30 | 수치 비교 (전/후) | 만족감 | 허무한 결말 |
| **판정** | 13:30–14:30 | 쓸 것 / 쓰지 말 것 / 조건 | 시그니처 | |
| **연결** | 14:30–15:00 | 다음 영상 1개만 지목 + 최종화면 | 세션 시청 연장 | 시청자 유실 |

### 절대 규칙
- ❌ **인트로 애니메이션 금지** — 0초부터 본론
- ❌ 0:00–0:45에 채널 소개·구독 요청 금지 (이탈 1위 원인)
- ✅ 구독 요청은 **가치 전달 직후 딱 1회**(실측 결과 직후, 5초)
- ✅ 12분 미만으로 내려가지 않는다 (시청시간 밀도)
- ✅ 20분을 넘기지 않는다 (완주율 붕괴)

## B. 롱폼 길이 전략 — 기둥별

| 기둥 | 목표 길이 | 목표 유지율 | 목표 AVD |
|---|---|---|---|
| P1 구축 | 15~20분 | 33% | **5.0~6.6분** |
| P2 검증 | 10~14분 | 40% | 4.0~5.6분 |
| P3 템플릿 | 8~12분 | 45% | 3.6~5.4분 |
| P4 신호 | 6~10분 | 50% | 3.0~5.0분 |

> **채널 평균 AVD 5분이 152일 목표의 생명선이다.** 매주 리뷰에서 이 수치만은 반드시 확인한다.

## C. 숏폼 규격 (30~50초)

| 구간 | 시간 | 내용 |
|---|---|---|
| 훅 | 0:00–0:02 | **결과 화면부터.** 텍스트 한 줄 동시 노출 |
| 전개 | 0:02–0:25 | 과정 3컷 압축. 컷당 최대 4초 |
| 반전/판정 | 0:25–0:40 | "그런데 이건 안 됩니다" |
| 유도 | 0:40–0:50 | "전체 과정은 채널에" (링크 아님, 채널 언급) |

### 규칙
- 세로 9:16 재구성 (단순 크롭 금지 — 화면 녹화는 중요 영역 확대 후 배치)
- **자막 필수, 무음 시청 전제**
- 첫 프레임에 텍스트가 반드시 있어야 한다
- ❌ 숏폼에서 "구독하세요" 직접 요청 금지 → 완주율 하락. **채널명 노출로 대체**
- ⚠️ 같은 템플릿의 숏폼을 하루 3개 이상 올리지 않는다 (대량생산 신호)

## D. 썸네일 규격

| 항목 | 규정 |
|---|---|
| 텍스트 | **최대 7글자**, 2줄 이내 |
| 대비 | 배경과 텍스트 명도차 최대. 채도 높은 색 1개만 |
| 구성 | 좌: 텍스트 / 우: 화면 캡처 1개 (고정 레이아웃) |
| 금지 | 화살표 남발, 놀란 얼굴 이미지, 빨간 동그라미 3개 이상 |
| 검증 | **가로 120px로 축소해서 읽히는지 확인** — 안 읽히면 폐기 |

### 썸네일 문구 공식 (7글자 이내)
- 결과형: `주5시간 절감` · `3분만에 완료`
- 판정형: `결국 지웠다` · `이건 안 됨`
- 대비형: `수동 vs 자동` · `유료? 무료?`
- 의문형: `진짜 될까` · `왜 안 되나`

## E. 제목 공식 (검색어 + 클릭 유발)

**구조: [검색어] + [구체 수치 또는 반전]**

| 유형 | 템플릿 | 예시 |
|---|---|---|
| 결과 명시 | `○○ 자동화했더니 [수치] 줄었습니다` | 정산 업무 자동화했더니 주 5시간 줄었습니다 |
| 실패 고백 | `○○ 30일 쓰고 [결론]한 이유` | AI 자동응답 30일 쓰고 결국 끈 이유 |
| 전 과정 | `○○ 만드는 전 과정 (실패 포함)` | 견적서 자동화 만드는 전 과정 |
| 비교 판정 | `○○ vs ○○ — [기준]으로 실측` | 도구 A vs B — 같은 작업 시켜봤습니다 |
| 조건 경고 | `○○ 도입 전에 확인할 [숫자]가지` | 업무 자동화 도입 전 확인할 5가지 |

### 제목 규칙
- **60자 이내** (모바일 잘림 방지)
- 검색어는 **앞쪽 30자 안에** 배치
- 숫자를 반드시 하나 포함
- ❌ 과장어(미쳤다·충격·소름) 금지 — 실무자 시청층과 불일치

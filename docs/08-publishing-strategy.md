# 08. 게시 전략

---

## 1. 발행 리듬

| 항목 | 규정 | 근거 |
|---|---|---|
| 롱폼 | **주 3편 — 화 / 목 / 토** | 61편/142일. 주 4편 이상은 정책상 대량생산 신호 + 품질 붕괴 |
| 숏폼 | **주 5편 — 월/화/수/목/금** | 구독자 엔진. 롱폼 파생물이므로 추가 부담 없음 |
| 발행 시각 (한국) | 롱폼 **20:00** / 숏폼 **12:30** | 핵심 페르소나의 시청 시점(밤 10시~자정)보다 2시간 앞서 배치 |
| 커뮤니티 탭 | 주 2회 (수·일) | 구독자 재활성화. D30 이후 사용 가능 |

### 왜 주 3편인가 (주 5편이 아니라)

| | 주 3편 | 주 5편 |
|---|---|---|
| 편당 품질 | 유지 가능 | 붕괴 |
| 정책 위험 | 낮음 | **대량생산 신호 점등** |
| 발행기간 총 편수 | 61편 | 101편 |
| 현실적 지속 가능성 | ✅ | ❌ 6주차에 중단 |

**편수를 늘리는 대신 길이와 유지율을 올린다** — 01 문서의 역산 결론과 일치.

## 2. 발행 순서 전략 — 무엇을 먼저 올리는가

### 준비 10일: 롱폼 6편 사전 제작 후 일괄 시작

**채널 개설 직후 빈 채널에 1편만 올리는 것은 최악의 선택이다.**
새 방문자가 "볼 게 없는 채널"을 보고 구독하지 않기 때문이다.

- **D1–D10 (준비 기간): 롱폼 6편을 미리 만들어 둔다**
- **공개일(D11)에 3편 동시 공개** → 즉시 "볼 게 있는 채널"이 된다
- 다음 날부터 정상 리듬(화·목·토) 진입

### 초기 12편의 주제 선정 원칙

| 순서 | 유형 | 이유 |
|---|---|---|
| 1~3편 | **가장 좁고 명확한 검색어** | 알고리즘에 채널 주제를 각인시킨다 |
| 4~8편 | 같은 주제군의 인접 질의 | 주제 클러스터 형성 → 추천 연쇄 |
| 9~12편 | 첫 성과 상위 2편의 후속편 | 데이터가 가리키는 방향으로 |

> ❌ **초반에 주제를 넓히지 마라.** 첫 12편이 서로 무관하면 유튜브가 채널을 분류하지 못해 아무에게도 추천하지 않는다.
> 이것이 신규 채널 실패의 최대 원인이다.

## 3. 재생목록 전략 (시청시간 증폭 장치)

**재생목록은 시청시간을 2배로 만드는 가장 저평가된 도구다.**

| 규칙 | 내용 |
|---|---|
| 개수 | 서브 니치당 1개, 최대 5개 |
| 배치 | 모든 영상은 **발행 즉시 최소 1개** 재생목록에 편입 |
| 순서 | 조회수순이 아니라 **학습 순서**(쉬움 → 어려움) |
| 이름 | 검색어 형태로 (`업무 자동화 처음부터` 등) |
| 활용 | 설명란 최상단에 해당 재생목록 링크 |

**효과: 자동 연속 재생 → 세션당 시청시간 1.6~2.2배.** 152일 목표에 직접 기여한다.

## 4. 메타데이터 규격

| 항목 | 규정 |
|---|---|
| 제목 | 60자 이내, 검색어 앞 30자 |
| 설명란 1~2줄 | **검색어 포함 요약** (검색 노출에 실제 영향) |
| 설명란 3~5줄 | 타임스탬프 (챕터 기능 활성화 → 유지율 상승) |
| 설명란 하단 | 재생목록 링크 + 관련 영상 2개 + **AI 합성 음성 사용 고지** |
| 태그 | 5~8개. 남발 금지 |
| 챕터 | **필수.** 최소 5개 이상 |
| 최종화면 | 마지막 12초. 다음 영상 1개 + 구독 버튼 |
| 카드 | 재훅 지점(5분·11분30초)에 관련 영상 1개씩 |

### AI 사용 공시 (정책 필수)
- 업로드 시 **"변경된 콘텐츠(altered content)" 공시 항목**을 정확히 체크한다
- 설명란에 한 줄 명시: `이 영상의 내레이션은 AI 합성 음성을 사용했습니다. 모든 화면·실행·결과는 직접 촬영·측정한 원본입니다.`
- 이 한 줄이 정책 심사에서 **"인간의 기여"를 증명하는 문장**이 된다

## 5. 발행 후 90분 프로토콜

발행 직후 90분의 반응이 알고리즘 초기 배포량을 결정한다.

| 시점 | 행동 |
|---|---|
| 0분 | 발행 + 커뮤니티 탭에 공유 |
| 0~10분 | **고정 댓글 작성** — 질문형으로 (댓글 유도) |
| 10~60분 | 달리는 댓글에 **전부 직접 답변** (자동화 금지 구간) |
| 60~90분 | CTR 확인. **6% 미만이면 썸네일 즉시 교체** |
| 24시간 | 유지율 그래프 확인 → 급락 지점 기록 → 다음 영상에 반영 |

> ⚠️ **댓글 응대는 절대 자동화하지 않는다.** 정책상 "진정한 인간 개입"의 가장 명확한 증거이며, 초기 채널의 최대 성장 레버다.

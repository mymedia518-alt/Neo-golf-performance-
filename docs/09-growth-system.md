# 09. 성장 시스템 — 운의 영역을 시스템으로 바꾼다

성장은 "좋은 영상을 만들면 된다"가 아니다. **4개의 독립 레버**를 각각 관리한다.

---

## 성장 방정식

```
성장 = 노출수 × CTR × AVD × 구독전환율
```

이 4개는 곱셈이다. 하나가 0이면 전부 0이다. **약한 것 하나만 고치면 전체가 뛴다.**

| 레버 | 우리가 통제 가능한가 | 통제 수단 | 목표치 |
|---|---|---|---|
| 노출수 | 간접 | 주제 선정 · 발행량 · 재생목록 | — |
| **CTR** | **직접** | 썸네일 + 제목 | **6~10%** |
| **AVD** | **직접** | 구조 설계 + 편집 | **5분+** |
| **구독전환율** | **직접** | 배치 + 가치 증명 | **롱폼 1%+** |

> **신규 채널이 통제할 수 있는 건 3개다. 이 3개에만 집중한다.**
> "노출이 안 나온다"는 불평은 무의미하다. 노출은 나머지 3개의 결과다.

---

## 레버 1. CTR — 패키징 시스템

### 제작 순서를 뒤집는다

❌ 일반적 순서: 영상 제작 → 썸네일 만들기
✅ **우리 순서: 제목·썸네일 먼저 확정 → 그 약속을 지키는 영상 제작**

**이유:** 클릭되지 않을 영상은 만들 이유가 없다. 패키징이 먼저 통과해야 제작에 들어간다.

### 패키징 게이트 (제작 착수 전 필수 통과)

| 체크 | 기준 |
|---|---|
| 1 | 제목만 보고 "이 영상이 뭘 주는지" 5초 안에 이해되는가 |
| 2 | 썸네일이 120px에서 읽히는가 |
| 3 | 제목과 썸네일이 **같은 말을 반복하지 않는가** (썸네일=결과, 제목=맥락) |
| 4 | 검색창에 제목의 검색어를 넣었을 때 상위 결과보다 구체적인가 |
| 5 | 과장 없이 지킬 수 있는 약속인가 |

**5개 중 1개라도 실패 → 제작 착수 금지, 주제 재설계.**

### CTR 개선 루프 (주 1회)

1. 최근 6편의 CTR 확인
2. 하위 2편 선정
3. **썸네일만 교체**(제목 유지) → 7일 관찰
4. 개선 없으면 **제목 교체**(썸네일 유지) → 7일 관찰
5. 변수를 동시에 바꾸지 않는다 (원인 특정 불가)

> 유튜브는 발행 후 며칠~몇 주가 지나도 썸네일 교체 효과가 반영된다. **과거 영상은 죽은 자산이 아니다.**

---

## 레버 2. AVD — 07 문서의 구조 + 편집 규칙

### 편집 3원칙 (자동화 가능)

| 원칙 | 실행 |
|---|---|
| **무음 제거** | 0.4초 이상의 침묵 전부 컷 |
| **대기 시간 압축** | 로딩·설치·처리 대기는 3~8배속 + "○초 후" 자막 |
| **화면 확대** | 중요 영역은 항상 확대. 전체 화면 그대로 보여주지 않음(모바일에서 안 보임) |

이 3가지만으로 체감 밀도가 크게 오르고 AVD가 상승한다.

### 유지율 그래프 판독법 (매주)

| 그래프 형태 | 진단 | 처방 |
|---|---|---|
| 0~15초 급락 30%+ | 훅 실패 또는 **제목-내용 불일치** | 훅 재설계. 제목이 과장이면 제목 수정 |
| 특정 지점 수직 낙하 | 그 지점이 지루하거나 어려움 | 해당 구간 압축·삭제 |
| 완만한 우하향 | 정상 | 유지 |
| 중간에 상승 구간 | **되감기 발생 = 좋은 신호** | 그 지점의 정보 밀도를 다른 영상에 복제 |

---

## 레버 3. 구독 전환율 — 무얼굴 채널의 최대 약점 공략

무얼굴 채널은 "사람"이 없어 구독 동기가 약하다. **동기를 인위적으로 설계한다.**

| 장치 | 배치 | 문구 |
|---|---|---|
| **시리즈 예고** | 영상 중반 | "이건 3부작 중 1편입니다" → 다음 편을 기다리게 함 |
| **가치 증명 직후 요청** | 실측 결과 직후 5초 | "이런 실측을 매주 합니다" (구독하세요 ❌) |
| **재생목록 유도** | 최종화면 | 같은 시리즈로 연결 |
| **고정 댓글** | 발행 즉시 | "다음엔 어떤 업무를 자동화할까요?" |
| **일관된 형식** | 전 영상 | 같은 구조 = 예측 가능 = 구독 가치 |

> **핵심: 무얼굴 채널의 구독 동기는 "사람"이 아니라 "형식의 신뢰"다.**
> 매번 같은 구조로 같은 품질을 주면, 시청자는 인격이 아니라 **포맷을 구독한다.**

---

## 레버 4. 숏폼 → 롱폼 깔때기

숏폼은 구독자를 데려오지만 **시청시간에는 기여하지 않는다.** 숏폼 시청자를 롱폼으로 옮겨야 한다.

| 장치 | 실행 |
|---|---|
| 숏폼 마지막 5초 | "전체 과정은 채널 첫 화면에" (링크보다 언급이 효과적) |
| 숏폼 고정 댓글 | 롱폼 제목 명시 |
| 채널 홈 설정 | **미구독자 대상 트레일러 = 최고 성과 롱폼** |
| 숏폼 선반 정리 | 롱폼과 숏폼 재생목록 분리 배치 |

**전환 목표: 숏폼 조회 1,000당 롱폼 조회 5~15회.** 낮아 보이지만 20만 조회 시 롱폼 1,000~3,000조회 = 시청시간 기여.

## 성장 진단 순서도 (성과가 안 나올 때)

```
성과 부진
  │
  ├─ 노출수가 낮은가? ──── 예 → CTR·AVD가 먼저다. 노출은 결과지 원인이 아님
  │                              → 하위 지표부터 점검
  │
  ├─ CTR < 4%? ────────── 예 → 패키징 문제. 썸네일 교체 루프 실행
  │
  ├─ AVD < 3분? ───────── 예 → 구조 문제. 훅·중반 재설계
  │
  ├─ 구독전환 < 0.5%? ─── 예 → 가치 증명 부족. P3 템플릿 비중 상향
  │
  └─ 전부 정상인데 정체 → 주제 문제. G2 게이트 피벗 규칙 적용
```

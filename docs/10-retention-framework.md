# 10. 유지 프레임워크 — 시청 유지 + 시청자 유지

"유지"에는 두 층이 있다. **영상 안에서의 유지(retention)**와 **채널에 대한 유지(returning viewer)**.
152일 목표에는 둘 다 필요하다.

---

## 층 1. 영상 내 유지 (시청시간 4,000h의 직접 원인)

### 이탈 지점 3곳과 방어 장치

| 이탈 구간 | 평균 이탈률 | 원인 | 방어 장치 |
|---|---|---|---|
| **0~15초** | 30~45% | 기대 불일치 | 훅 = 결과 화면 선노출 |
| **2~4분** | 15~25% | 준비·설명 지루함 | 재훅 + 배속 압축 |
| **중반 이후** | 10~20% | "내 상황과 다름" | 분기 안내 + 실패 구간 |

### 훅 공식 5종 (0~20초)

| 공식 | 구조 | 예시 |
|---|---|---|
| **결과 선공개** | 완성 화면 → "이걸 만들었습니다" | 자동 생성된 정산표를 먼저 보여줌 |
| **수치 충돌** | "5시간 → 4분" 숫자 대비 | 전/후 스톱워치 화면 분할 |
| **실패 예고** | "결론부터: 절반만 됩니다" | 기대치 조정 = 이탈 방지 |
| **질문 정면** | "○○ 진짜 되나? 직접 해봤습니다" | 검색 의도 즉시 확인 |
| **비용 공개** | "3만원 쓰고 알아낸 것" | 손실 회피 자극 |

**금지 훅:** "안녕하세요", "오늘은", "구독과 좋아요", 채널 소개, 배경 설명

### 재훅 배치 규칙
- 영상 길이 ÷ 3 지점마다 1회
- 재훅 문장 형태: **"그런데 여기서 문제가 생깁니다"** / **"결과가 예상과 달랐습니다"**
- 재훅은 다음 구간의 **가치를 예고**하는 문장이어야 한다. 단순 전환어는 효과 없음

### 오픈 루프 기법
영상 초반에 답을 주지 않고 열어둔다.
> 예: 0:30에 "이 방법엔 치명적인 단점이 하나 있는데, 그건 9분쯤에 말씀드립니다"
> → 해당 시점까지 유지율이 유의미하게 상승한다. **단, 반드시 약속한 시점에 답을 준다.** 안 지키면 신뢰가 깨진다.

## 층 2. 채널 유지 (구독자 1,000명 + 재방문)

### 재방문 시청자 30% 만들기

| 장치 | 작동 원리 |
|---|---|
| **고정 발행일** (화·목·토 20시) | 습관 형성. 무작위 발행은 습관을 못 만든다 |
| **시리즈화** | "○○ 자동화 3부작" — 다음 편을 기다리는 상태 |
| **동일 구조** | 매번 같은 순서 = 인지 부하 0 = 편안함 |
| **커뮤니티 탭** (주 2회) | 발행 없는 날의 접점 유지 |
| **댓글 전수 응대** (D60까지) | 관계 형성. 초기 100명이 채널을 만든다 |

### 시리즈 설계 예시

| 시리즈 | 편수 | 구조 |
|---|---|---|
| `1인 사업자 자동화 기초` | 5편 | 순서대로 따라 하면 시스템 완성 |
| `도구 실측 시리즈` | 무한 | 같은 테스트 조건, 대상만 교체 |
| `이 채널 만드는 법` | 6편 | 자기참조 — 152일 기록 자체가 콘텐츠 |

> **`이 채널 만드는 법` 시리즈는 전략적으로 중요하다.** 채널 운영 과정 자체가 원본 데이터이므로 정책상 가장 안전하고, 시청자에게는 실시간 증거가 된다.

## 층 3. 정책 유지 (채널 생존)

**수익화 요건을 채워도 정책에서 걸리면 전부 무효다.** 매주 자가 점검한다.

### 주간 정책 자가 점검표

| 항목 | 확인 |
|---|---|
| 이번 주 영상에 **직접 녹화한 원본 화면**이 있는가 | ☐ |
| 이번 주 영상에 **직접 측정한 수치·결과**가 있는가 | ☐ |
| 이번 주 영상 3편의 **구조는 같아도 내용은 완전히 다른가** | ☐ |
| 발행 전 **사람이 전체를 처음부터 끝까지 봤는가** | ☐ |
| **AI 합성 요소를 공시**했는가 | ☐ |
| 남의 영상·기사를 **그대로 옮긴 부분이 없는가** | ☐ |
| 댓글에 **사람이 직접 답했는가** | ☐ |

**7개 중 하나라도 ☐이면 발행을 미룬다.** 152일 안에 요건을 채우는 것보다 채널이 살아 있는 것이 우선이다.

### 위험 신호 조기 감지

| 신호 | 의미 | 조치 |
|---|---|---|
| 특정 영상만 노출이 급감 | 품질/정책 필터 가능성 | 해당 영상 재검토, 유사 포맷 중단 |
| "제한적 광고" 표시 다수 | 광고주 친화성 문제 | 제목·썸네일 표현 순화 |
| 채널 전체 노출 급감 | 채널 단위 평가 하락 | **즉시 발행 속도를 줄이고 편당 품질 상향** |

> 마지막 항목이 중요하다. 성과가 나빠질 때 발행량을 늘리는 것은 자동화 채널의 전형적 자살 경로다. **나빠지면 줄이고 깊게 간다.**

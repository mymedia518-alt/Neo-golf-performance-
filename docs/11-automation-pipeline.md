# 11. 자동화 파이프라인 — 롱폼 1편을 90분에 만드는 공정

## 설계 원칙

> **자동화의 목표는 "사람을 빼는 것"이 아니라 "사람을 원본성이 생기는 지점에만 남기는 것"이다.**

| 구분 | 처리 방식 | 근거 |
|---|---|---|
| 🤖 **완전 자동** | 도구가 처리, 사람은 승인만 | 원본성과 무관한 공정 |
| 🧑 **인간 전담** | 절대 자동화 금지 | 정책상 "진정한 인간 기여"의 근거 |
| 🤝 **협업** | 도구가 초안, 사람이 판단 | 품질 결정 지점 |

---

## 공정 전체 흐름 (롱폼 1편 = 실작업 90분)

| # | 단계 | 담당 | 소요 | 산출물 |
|---|---|---|---|---|

## 단계별 상세

### 1. 수요 수집 🤖 (주 1회 배치, 30분)

수집 소스:
- 유튜브 검색 자동완성 (서브 니치 키워드 10개 × 자동완성 20개)
- 유튜브 검색 필터: `이번 달` + `조회수순` → 최근 승자 확인
- 네이버 데이터랩 검색어 트렌드 (한국어 수요 검증에 유효)
- 커뮤니티·Q&A의 실제 질문 문장 수집
- 경쟁 채널 최근 30일 상위 영상

**출력 형식:** `주제 / 추정 검색의도 / 경쟁강도(05 문서 기준) / 해당 기둥 / 예상 길이`

> 자동 수집한 목록에서 **최종 선택은 사람이 한다.** 자동 선택하면 전 영상이 비슷해진다(= 정책 위험).

### 2. 주제·패키징 확정 🧑 (10분)

- 09 문서의 **패키징 게이트 5개 통과** 필수
- 통과 못 하면 제작 착수 금지

### 3. 실제 작업 + 화면 녹화 🧑 — **이 공정이 채널의 생명선**

| 규칙 | 이유 |
|---|---|
| 반드시 **처음부터 끝까지 한 번에** 녹화 | 실패 장면이 자연스럽게 남는다 |
| 실패해도 **다시 찍지 않는다** | 실패가 콘텐츠다 |
| 시작·종료 시각을 **기록**한다 | 실측 수치의 근거 |
| 원본 녹화 파일을 **전부 보관**한다 | 정책 소명 시 원본 증거 |

> ⚠️ **이 단계를 건너뛰고 AI 생성 화면으로 대체하는 순간 이 채널은 정책상 사망한다.** 30분을 아끼려다 프로젝트 전체를 잃는다.

### 4. 대본 작성 🤝 (10분)

AI에게 주는 입력:
- 화면 녹화 타임라인 요약
- 실측 수치
- 막힌 지점과 해결 방법
- 최종 판정

AI에게 요구하는 출력: **07 문서의 타임코드 구조에 정확히 맞춘 내레이션**

**인간 검수 항목 (필수):**
- 수치가 실제와 일치하는가
- 과장 표현이 들어갔는가 → 삭제
- 판정이 본인 의견과 같은가

### 5. 음성 합성 🤖 (3분)
- **고정 음성 1개** (152일 동안 변경 금지)
- 속도 1.05~1.1배
- 문장 사이 자연스러운 호흡 유지

### 6. 편집 🤖→🧑 (20분)
자동 처리:
- 0.4초 이상 무음 컷
- 대기 구간 3~8배속 + "○초 후" 자막
- 중요 영역 자동 확대
- 자막 자동 생성

인간 처리:
- 재훅 지점 2곳 배치
- 실패 구간 남길지 판단
- 최종 리듬 확인

### 7. 보조 비주얼 🤖 (5분)
- 구조 다이어그램, 전/후 비교 그래픽
- 이미지·영상 생성 도구 활용
- ⚠️ **B롤이 영상의 절반을 넘지 않게 한다.** 화면 녹화가 주인공이어야 정책상 안전하다

### 8. 썸네일 🤖→🧑 (5분)
- 고정 브랜드 템플릿에 텍스트·캡처만 교체 (디자인 도구 템플릿 기능 활용)
- **3안 생성 → 120px 축소 테스트 → 1개 선택**

### 9. 메타데이터 🤖 (2분)
- 제목(확정본) / 설명 3단 구조 / 챕터 / 태그 / 재생목록 배정
- **AI 합성 음성 고지 문구 자동 삽입**

### 10. 최종 인간 검수 🧑 — **생략 절대 금지**

| 확인 | |
|---|---|
| 처음부터 끝까지 재생해서 봤다 | ☐ |
| 사실·수치 오류가 없다 | ☐ |
| 제목의 약속을 영상이 지킨다 | ☐ |
| 10 문서의 정책 자가 점검 7항목 통과 | ☐ |

### 11. 숏폼 추출 🤖→🧑 (15분)
- 06 문서의 5개 유형에서 3~5개 추출
- 세로 재구성 시 **단순 크롭 금지** — 핵심 영역 확대 후 배치
- 자막 필수

### 12. 다국어 오디오 트랙 🤖 (D46 이후)
- 조회수 상위 20% 영상만 대상
- 더빙 후 유튜브 **다국어 오디오 트랙**으로 업로드 (별도 채널 ❌)
- 영어 제목·설명 동시 등록

## 자동화 금지 목록 (요약 — 벽에 붙일 것)

| ❌ 절대 자동화 금지 | 이유 |
|---|---|
| 화면 녹화 / 실제 작업 수행 | 원본성의 유일한 원천 |
| 실측 수치 생성 | 조작이 되며, 신뢰가 붕괴한다 |
| 최종 판정·의견 | 채널의 관점 = 브랜드 |
| 발행 전 최종 검수 | 정책상 인간 개입 증거 |
| 댓글 응대 | 관계 형성 + 정책 증거 |
| 주제 최종 선택 | 자동 선택 시 콘텐츠가 균질화됨 |

## 배치 처리 전략 (주간)

동일 작업을 몰아서 처리하면 전환 비용이 사라진다.

| 요일 | 배치 작업 |
|---|---|
| 월 | 수요 수집 + 주간 3편 패키징 확정 |
| 화·수 | **화면 녹화 3편 연속** (가장 큰 시간 절약) |
| 목 | 대본 3편 + 음성 3편 |
| 금 | 편집 + 썸네일 + 메타 3편 |
| 토 | 숏폼 5개 일괄 추출 |

→ 발행은 예약으로 자동화. **제작일과 발행일을 분리한다.**

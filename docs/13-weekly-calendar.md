## 시간 배분 요약

| 구분 | 주간 소요 | 비중 |
|---|---|---|
| 화면 녹화 (원본 생성) | 2시간 15분 | 18% |
| 발행 후 응대 | 4시간 30분 | 36% |
| 제작·편집·검수 | 4시간 45분 | 38% |
| 기획·분석 | 1시간 30분 | 12% |
| **합계** | **약 13시간** | |

> **주목: 가장 큰 시간 항목이 "댓글 응대"다.** 이것은 낭비가 아니라 초기 채널의 최대 성장 레버이자 정책 안전장치다.
> 시간을 줄여야 한다면 편집 품질을 줄이고, 응대는 D60까지 유지한다.

## 압축 모드 (주 8시간만 가능할 때)

| 조정 | 방법 |
|---|---|
| 롱폼 주 3편 → **주 2편** (화·금) | 시청시간 목표는 길이 상향(18~22분)으로 보전 |
| 숏폼 주 5편 → **주 3편** | 구독자 확보 속도는 늦어지지만 유지 |
| 발행 후 프로토콜 90분 → **45분** | 첫 30분 집중 응대만 |
| 커뮤니티 탭 주 2회 → **주 1회** | |

⚠️ **압축 시에도 절대 줄이지 않는 것: 화면 녹화, 최종 인간 검수, 정책 자가 점검.**

## 확장 모드 (팀·외주 투입 시)

| 역할 | 담당 |

| **본인 유지** | 화면 녹화, 주제 선정, 판정, 최종 검수, 댓글 |

# 14. KPI 대시보드 & 의사결정 규칙

숫자를 보는 목적은 안심이 아니라 **다음 행동을 결정하는 것**이다. 각 지표에 행동 규칙을 붙인다.

---

## 1. 주간 확인 지표 (매주 월요일 30분)

| 지표 | 목표 | 🔴 위험 | 🟡 주의 | 🟢 정상 | 위험 시 행동 |
|---|---|---|---|---|---|
| **누적 시청시간** | 로드맵 대비 100% | <70% | 70~90% | >90% | 영상 길이 상향 + 재생목록 점검 |
| **누적 구독자** | 로드맵 대비 100% | <70% | 70~90% | >90% | 숏폼 비중 상향 + P3 템플릿 증편 |
| **평균 AVD** | 5분+ | <3분 | 3~4.5분 | >5분 | **최우선 조치.** 훅·구조 재설계 |
| **CTR** | 6~10% | <4% | 4~6% | >6% | 썸네일 교체 루프 |
| **조회당 구독 (롱폼)** | 1%+ | <0.4% | 0.4~0.8% | >1% | 가치 증명 배치 재설계 |
| **주간 발행 수** | 롱폼 3 / 숏폼 5 | 롱폼 <2 | 롱폼 2 | 3 | 압축 모드 전환 |
| **재방문 시청자 비율** | 30%+ | <10% | 10~25% | >25% | 시리즈화·고정 발행일 강화 |

### 우선순위 규칙
여러 지표가 동시에 나쁘면 **이 순서로만 손댄다.**

```
1. AVD          ← 시청시간의 직접 원인. 여기가 최우선
2. CTR          ← 노출을 조회로 바꾸는 관문
3. 구독전환율    ← 1,000명 목표
4. 발행량       ← 마지막. 앞의 3개가 나쁜데 발행량을 늘리면 손실만 커진다
```

> **가장 흔한 실수: 성과가 나쁠 때 발행량부터 늘리는 것.**
> 유지율이 낮은 영상을 2배로 만들면 낮은 유지율이 2배가 될 뿐이고, 대량생산 정책 신호까지 켜진다.

## 2. 영상별 판정 (발행 7일 후)

각 영상을 4분면에 놓고 다음 행동을 결정한다.

| | **CTR 낮음 (<4%)** | **CTR 높음 (>6%)** |
|---|---|---|
| **AVD 높음 (>5분)** | 🔧 **패키징 실패** — 내용은 좋다. 썸네일·제목 교체하면 살아난다. **최우선 재작업 대상** | ⭐ **성공** — 이 주제·구조를 3편 더 만든다 |
| **AVD 낮음 (<3분)** | ❌ **폐기** — 주제 자체가 안 맞음. 반복하지 않는다 | ⚠️ **낚임** — 제목이 과장. 신뢰 손상 위험. **제목을 정직하게 수정** |

> 우상단(성공)은 복제하고, 좌상단(패키징 실패)은 재작업하고, 우하단(낚임)은 즉시 수정하고, 좌하단은 버린다.
> **좌상단이 가장 이익이 큰 구간이다.** 이미 좋은 영상을 만들어 놨는데 클릭이 안 될 뿐이므로, 썸네일 교체 20분에 조회수가 몇 배로 뛴다.

## 4. 중단·전환 규칙 (사전에 정해두면 감정으로 결정하지 않는다)

| 상황 | 규칙 |
|---|---|
| D30에 누적 100시간 미만 | **중단하지 않는다.** P1은 자산 적재 구간이다. 발행만 유지 |
| D60에 롱폼 중앙값 조회수 <150 | **하위 주제 피벗.** 상위 3편의 공통점으로 70% 집중 (채널은 유지) |
| D90에 구독 500 + 3,000시간 | **팬 펀딩 티어 즉시 지원** |
| D120에 누적 <2,000시간 | 애드센스 152일 달성 포기 → **플랜 B 전환**(팬 펀딩 + 8,000시간 장기전) |
| 채널 전체 노출 급감 | **발행량 감소 + 편당 품질 상향.** 절대 발행량을 늘리지 않는다 |
| 특정 포맷이 3회 연속 하위 | 그 포맷 중단 |

## 5. 보지 말아야 할 지표

| 지표 | 왜 무시하는가 |
|---|---|
| 좋아요 수 | 알고리즘 영향이 미미하고 감정만 흔든다 |
| 실시간 조회수 | 시간 낭비. 7일 단위로만 본다 |
| 다른 채널의 구독자 수 | 출발 시점이 다르다. 비교는 동기를 파괴한다 |
| 숏폼 조회수 총합 | **시청시간에 기여하지 않는다.** 오직 구독 전환수만 본다 |

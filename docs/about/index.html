About NEO GOLF DATA

가능성을 읽는 것으로

골프 리더보드는 현재의 결과를 보여줍니다.
NEO GOLF DATA는 그 결과에서 한 걸음 더 나아가 질문합니다.

지금 이 선수의 우승 가능성은 얼마나 될까?

현재 순위가 같아도 왜 선수마다 가능성은 다를까?

어제의 예측은 오늘 실제 경기에서 얼마나 맞았을까?

NEO GOLF DATA는 이런 질문을 데이터로 확인하기 위해 시작한 독립적인 KLPGA 골프 데이터 분석 프로젝트입니다.

NEO GOLF DATA가 하는 일

NEO GOLF DATA는 KLPGA 공개 경기 데이터를 기반으로 선수들의 축적된 경기력과 현재 대회 결과를 분석합니다.

대회 시작 전 선수들의 가능성을 계산하고, 실제 라운드가 끝날 때마다 새롭게 확인된 경기 결과를 반영해 남은 대회의 가능성을 다시 계산합니다.

현재 제공하는 주요 데이터는 다음과 같습니다.

  • 우승 확률
  • TOP 5 진입 확률
  • TOP 10 진입 확률
  • TOP 20 진입 확률
  • 컷 통과 확률
  • 라운드별 확률 변화
  • 예측과 실제 결과의 비교

실시간이 아니라, 라운드별로 업데이트합니다

NEO GOLF DATA의 확률은 경기 중 샷 하나마다 변하는 실시간 확률이 아닙니다.

대회 전 → 1라운드 종료 → 2라운드 종료 → 이후 라운드 종료

각 시점의 공식 경기 결과를 반영해 모델을 다시 계산합니다.

따라서 하나의 숫자보다 선수의 가능성이 대회를 치르면서 어떻게 변하는가를 보여주는 데 초점을 맞춥니다.

예측보다 중요한 것은 검증입니다

NEO GOLF DATA는 결과가 나온 뒤 과거의 예측을 결과에 맞춰 수정하지 않습니다.

각 라운드에서 공개한 예측을 그대로 보존하고 실제 경기 결과와 비교합니다.

맞은 예측도 기록하고, 틀린 예측도 기록합니다.

예측→결과→검증→개선

이 과정을 반복하면서 모델이 실제 골프 대회를 얼마나 잘 설명하고 있는지를 계속 확인합니다.

NEO GOLF DATA가 만들고 싶은 것은 단순히 높은 확률을 보여주는 사이트가 아니라, 자신의 예측을 기록하고 검증하는 골프 데이터 플랫폼입니다.

Independent Golf Data Project

독립 프로젝트 안내

NEO GOLF DATA는 독립적으로 개발·운영되는 골프 데이터 프로젝트입니다.

Data Golf를 포함한 특정 해외 골프 데이터 서비스의 한국판이 아니며, 해당 서비스와 제휴·라이선스·운영 또는 모델 공유 관계가 없습니다.

현재는 KLPGA를 중심으로 데이터를 수집하고 모델을 검증하고 있으며, 축적된 결과를 바탕으로 분석 범위를 단계적으로 확장해 나갑니다.

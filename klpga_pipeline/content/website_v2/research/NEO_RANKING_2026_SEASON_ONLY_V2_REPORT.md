# 2026 시즌 NEO 랭킹 V2

## 기준일

2026년 10월 18일 종료 기록까지 반영했다. 기존 10월 4일 기준 점수에 날짜만 바꾼 것이 아니라, 아이스버그골프·서울신문 오픈의 R1·R2·R3 공식 SG 라운드 기록을 추가해 전체 점수와 출전 수를 다시 계산했다.

## 반영 자료

| 자료 | 행 수 | 확인 자료 |
|---|---:|---|
| 기존 기준일(10월 4일)까지 식별된 2026 시즌 SG | 7,947 | `historical_sg_warehouse_corrected_v2.json`, 공식 대회 날짜표 |
| 아이스버그골프·서울신문 오픈 R1 | 107 | `ICEBERG_2026100003_R1_SG_OFFICIAL_V1.json` |
| 아이스버그골프·서울신문 오픈 R2 | 102 | `ICEBERG_2026100003_R2_SG_OFFICIAL_V1.json` |
| 아이스버그골프·서울신문 오픈 R3 | 61 | `raw_capture/2026100003_fr/sg_r3.html` 공식 SG 화면 |
| 합계 | 8,217 | 중복 선수·대회·라운드 조합 0건 |

R3 화면의 선수 이름은 공식 출전 선수 자료의 선수 ID와 연결했다. 61개 행 모두 연결됐고, R1~R3 자료에서 중복이나 값 충돌은 발견하지 않았다.

## 산출 기준

- 2026시즌 공식 라운드별 SG Total 기록만 사용했다.
- 최근 기록에 더 큰 비중을 주는 365일 반감기 가중치를 적용했다.
- 표본이 적을 때 점수가 과도하게 움직이지 않도록 32라운드 사전 표본 조정을 적용했다.
- 점수는 가중 SG 평균에 유효 표본 비율을 곱해 계산했다.
- 40라운드 이상은 정식 순위, 20~39라운드는 참고 순위로 표시했다. 40라운드 기준은 잠정 기준이며 검증된 우월 기준이 아니다.
- 정식 순위 선수 전원을 먼저 점수순으로 배열하고, 120명까지 참고 순위 선수를 추가했다.

## 결과

- 기록이 확인된 선수 297명
- 정식 순위 108명
- 20~39라운드 선수 15명 중 상위 12명을 참고 순위로 표시
- 전체 표시 120명
- 10월 4일 V1에 표시된 120명의 점수·라운드 수·대회 수는 기존 원천으로 재계산한 결과와 모두 일치했다.

## 집계 차이 안내

V1 요약 보고서에는 전체 집계가 7,970라운드·295명으로 기재돼 있다. 현재 보존된 식별 완료 원천에서 동일한 기간과 단일 라운드 범위를 재구성하면 7,947라운드·291명이다. 다만 V1에 공개된 120명은 점수·라운드·대회 수가 전부 일치했고, V2의 120명 구성도 동일하게 유지됐다. 이번 페이지는 확인 가능한 원천 7,947행과 새 대회 270행을 기준으로 갱신했다.
